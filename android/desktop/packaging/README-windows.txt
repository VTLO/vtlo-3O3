VTLO 3O3 for Windows

Double-click "VTLO 3O3.exe". No installation needed; the Java runtime is
included. Your patterns and samples are saved in %APPDATA%\VTLO 3O3.

Keys: Space run/stop, Tab next screen (F1-F3 jump), Esc panic.
Bass line: Z S X D C V G B H N J M , play the keyboard.
Sampler: Q W E R / A S D F play pads 1-8.
Right-click a step: gate (bass) or accent (drums, sampler).
Knobs: drag up/down or use the mouse wheel; double-click resets.
