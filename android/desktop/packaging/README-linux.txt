VTLO 3O3 for Linux (x86-64)

Debian, Ubuntu, Mint…:  sudo apt install ./vtlo-3o3_1.0.0_amd64.deb
  then start "VTLO 3O3" from the applications menu (Sound & Video).

Any distribution: unpack VTLO-3O3-linux-x64.tar.gz and run
  "VTLO 3O3/bin/VTLO 3O3"
No installation needed; the Java runtime is included. Your patterns and
samples are saved in ~/.vtlo-3o3.

A short guide in French opens on first launch; the ? button shows it again.
Keys: Space run/stop, Tab next screen (F1-F3 jump), Esc panic.
